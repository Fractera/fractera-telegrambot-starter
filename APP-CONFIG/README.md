# APP-CONFIG — собственные настройки службы

Сегодня здесь ровно одно значение — **часовой пояс человека** (`timezone`), и папка заведена
2026-09-06 ради него.

## ✗ Чем оплачена: читатель и писатель смотрели в разные файлы

Измерено на сервере в день заведения:

```
читатель  timezoneOf()    → APP_CONFIG_PATH = /opt/fractera/app/APP-CONFIG/app-config.json  (порт 3000)
писатель  saveTimezone()  → process.cwd()/APP-CONFIG/app-config.json                        (своё дерево)
                            ls: No such file or directory
```

То есть бот спрашивал у человека часовой пояс, **записывал ответ в несуществующую папку** и на
следующем запросе читал чужой файл, где пояса нет. Отказ молчаливый: «напомни завтра в десять»
ставилось по Гринвичу навсегда, и человек узнал бы об этом, проспав встречу.

**Лечение — не правка кода, а совпадение адресов:** папка заведена в дереве службы, а
`APP_CONFIG_PATH` из `.env.local` убран. Теперь `process.cwd()/APP-CONFIG/` — это одно и то же
место для обоих.

## Почему приложение сюда ПИШЕТ

Отступление от закона «панель пишет, приложение читает», названное вслух ещё 2026-08-23 решением
владельца: «до поля в настройках мало кто дойдёт, поэтому записывай сразу». Пояс, о котором
человека не спросили, остаётся пустым навсегда, а напоминания при этом молча врут.

Отступление сужено до предела: правится **один ключ**, файл читается и перезаписывается целиком со
слиянием, схема не трогается.

## Что здесь НЕ лежит

Всё остальное, что бывает в `APP-CONFIG` порта 3000 — имя сайта, логотип, SEO, меню, валюта. Шапка
и подвал службы этого не читают вовсе: имя «Fractera» захардкожено, меню нет,
`components/shell/` не импортирует ни одного конфига.
