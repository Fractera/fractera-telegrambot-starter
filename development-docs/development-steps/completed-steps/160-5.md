# 160-5 — `remember_many`: свободный рассказ пишется одним вызовом

**Коммит:** `283216f`. **Дата:** 2026-09-08.

## Зачем

🔒 **ЗАКОН 158-4: ДОРОГО СТОИТ ХОД МОДЕЛИ, А НЕ ЗАПРОС К БАЗЕ.** «Меня зовут Рома, я на Канарах,
обращайся на ты» — три факта. Тремя вызовами это три хода рассуждения; одним — один.

🛑 **ЭТО НЕ ЗАМЕНА `remember`, А ЕГО ФОРМА ДЛЯ ПАЧКИ.** Один факт пишется одним вызовом: заставлять
агента заворачивать одиночную запись в список значило бы усложнить частый случай ради редкого.

## Главное решение

🔒 **ОТКАЗ ПО ОДНОМУ ФАКТУ НЕ ОТМЕНЯЕТ ОСТАЛЬНЫЕ.** Человек рассказал о себе тремя фразами; потерять
две из-за одной значило бы наказать его за то, что он сказал лишнее.
🛑 **И ОБРАТНОЕ ЗАПРЕЩЕНО ТОЖЕ:** молча проглотить неудачную запись. В ответе перечислено, что
записано и что нет, с причиной по каждой строке.

## Доказательства

```
✓ пачкой записано: 3 из 3
✓ из трёх записано 2, отвергнут 1 (material.text: not-a-person-fact) — остальные не пострадали
✓ пустой список: 400 no-facts
PROBE_RC=0
```

*Второй замер — главный:* смешанная пачка, где один факт заведомо не о человеке. Записаны два,
отвергнут один, причина названа. *Негативный контроль:* пустой список даёт честный отказ, а не
«ок, ноль записей» — иначе агент решил бы, что записал.

## Ошибки

- ✗ **Новый примитив требовал корпус** и падал с `unknown-corpus`: проверка, добавленная для
  читателей, молча распространилась на писателя, которого тогда ещё не было. 🔒 Урок: **условие,
  написанное как «все, кроме перечисленных», ловит каждого следующего**.

## Эволюция навыков

🔒 **В `create-registry-entry` просится строка о примитивах доступа:** добавляя шестой, проверить все
условия вида «кроме recall и remember» — их пишут перечислением, и новый в перечисление не попадает.
