# 143-2 — протокол закрытия: условия из фактов, ничего молча

**Коммит:** `0e544eb`, ветка `new-step-A`. **Дата:** 2026-09-07. **Девятый подшаг серии A.**
Замысел — `PASSPORT.md` §3е.

## Что делали и как

`lib/automations/closing.ts`: `decideClosing()` возвращает **пять решений с причинами при любом
исходе**, `isInteresting()` переводит слова владельца о содержательном цикле в правило над
записанными фактами.

**Решения:** закрытие **зовёт** описанное, а не переизобретает — своего канала заявок в модуле нет
(измерено: ноль сетевых обращений) · условия считаются из фактов прогона, а не из впечатления
модели · решение «не делать» тоже возвращается: пустой список читается как «ничего не случилось» ·
два рода закрытия различаются здесь, а не у вызывающего.

## Доказательства

**1. Прибор на функции решения** (`PROBE_RC=0`), десять проверок, из них пять негативных:

```
простая автоматизация: ни одно из пяти не запущено, у каждого названа причина
содержательная, закрыта целиком: отзыв ДА, публикация ДА, предложение признака ДА,
   заявка НЕТ («инструменты сработали — задача решена имеющимся»),
   ступень НЕТ («закрыта целиком — следующей ступени нет по определению»)
та же, закрыт ШАГ: ступень ДА, отзыв НЕТ («спрашивать рано»)
второй отзыв за тот же номер не запрашивается
```

**2. Код:** ноль сетевых обращений и ноль своих каналов в `lib/automations`; негативный контроль —
образец находит упоминание заявки в комментарии-вызове (1), то есть он не слепой. `TSC_RC=0`.

## Ошибки

- ✗ **Прибор нашёл дефект в моём же коде.** При закрытии шага решение было «нет», а причина
  объясняла **обратное** — «у автоматизации есть публичный договор». Это прямое нарушение закона
  «ничего молча»: **причина, не объясняющая решение, хуже молчания, потому что выглядит
  объяснением**. Исправлено; добавлена проверка, ловящая этот класс впредь.

## Эволюция навыков

**Что стоит добавить в `use-testing`:** проверять не только «правильно ли решение», но и **«объясняет
ли причина именно это решение»**. Текст рядом с булевым значением расходится с ним молча — тот же
класс, что число рядом с перечислением.
