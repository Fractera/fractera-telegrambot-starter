# 143-6 — отзыв: просят один раз, вердикт ложится в запись

**Коммит:** `e8b3d75`. **Дата:** 2026-09-08. Замысел — `PASSPORT.md` §3б, §3е.

## Что делали и как

Дверь `app/api/agent/feedback` и инструмент `feedback` у агента. Колонка `feedback_note` добавлена
по лестнице — образец, лестница и карта поля правлены **одной правкой**.

✗ **Измерено при планировании:** колонки `verdict_liked` и `verdict_needs_work` существовали с 138 и
**не имели ни одного писателя** — их только читали, чтобы решить, спрашивать ли отзыв. Система умела
вечно спрашивать и не умела записать ответ: «уже спрашивали» не наступало никогда.

🔒 **Закрытие не спрашивает само — оно возвращает решение «спросить».** Вопрос задаёт агент словами;
вторая поверхность вопроса была бы второй реализацией отзыва.

## Доказательства

**1. Прибор — вопрос гаснет после ответа:**

```
✓ отзыв спрошен: цикл содержательный: звались инструменты либо разбор был длинным
✓ отзыв записан: liked=yes
✓ второй раз отзыв НЕ спрашивают: отзыв по этому номеру уже запрашивали
```

*Негативный контроль:* до записи то же закрытие давало «да» — значит гасит именно запись, а не
что-то ещё.

**2. Замок и форма:**

```
✓ пустой отзыв отвергнут: HTTP 400 (no-verdict)
✓ отзыв без секрета: HTTP 401
```

*Что доказывает:* пустой отзыв не записывается — иначе «уже спрашивали» стало бы истиной при
отсутствии ответа человека. Молчание не отзыв.

## Ошибки

- ✗ **Добавив колонку в образец, я не обеспечил её появление на живой таблице** — чтение поимённо
  падало, и наружу это выглядело как `404 not-found`. Найдено прибором 143-4, исправлено там же:
  обе двери поднимают лестницу перед чтением.

## Эволюция навыков

🔒 **В корпус просится правило: колонка добавляется ЧЕТЫРЬМЯ правками, а не тремя** — форма,
лестница, образец **и вызов лестницы у каждого, кто читает поимённо**. Три из четырёх дают отказ,
который выглядит как «записи нет».
