# 164-3 — спутники ответа считаются одновременно: всплески первого уровня убраны

**Репозиторий:** `fractera-telegrambot-starter`. **Коммит:** `093f4a3`. **Дата:** 2026-09-08.
**Сервер:** `BUILD_RC=0`, сквозной прогон 6/6.

## Что делали и как

Третий прогон сквозного теста показал 4,87 и 4,33 секунды там, где раньше было 0,25 — на **первом
уровне**, который по замыслу должен быть мгновенным. Вместо объяснения «холодный старт» — замер:
десять чтений подряд без записей.

```
по ключу:  138 184 166 335 323 168 1070 175 290 1551
словами:  1262 193 227 170 1343 621 176 229 542 213
```

**Причина найдена чтением своего же кода:** каждое чтение делало **три последовательных** похода в
слой данных — само значение, список признаков для очереди знакомства и язык человека. Причём язык
спрашивался дважды: отдельно для знакомства и отдельно для предложения запомнить находку. Это мой
дефект из 163-2: способность добавлена верно, а цена её не измерена.

🔒 **ЛЕЧЕНИЕ — ОДНОВРЕМЕННОСТЬ, А НЕ ОТКАЗ ОТ СПОСОБНОСТИ.** Спутники ответа считаются параллельно с
основным чтением, язык спрашивается один раз на ответ.

## Доказательства

### 1. Замер «до» и «после» — плоскость измерения

**До:** максимум 1551 мс по ключу, 1343 словами.
**После, пятнадцать замеров:**

```
по ключу:  655 280 223 290 174 144 289 408 354 150 401 294 165 167 165
словами:   569 226 271 157 809 142 194 542 686 314 356 811 1074 385 210
```

Максимум по ключу упал с **1551 до 655 мс** (и это первый, холодный замер), типичный — 150–300.

### 2. Сквозной прогон — плоскость поведения

```
1. по ключу, только база      0.17   РАБОТАЕТ
2. словами, только база       0.19   РАБОТАЕТ
5. глубина 3 с разрешением    1.79   РАБОТАЕТ
```

Лучшие показатели за все прогоны, при 6/6. **Негативный контроль:** способность не потеряна —
знакомство и предложение запомнить по-прежнему приходят, что проверяют приборы 163-2 и 162-9.

## Ошибки

🛑 **Я ДОБАВИЛ СПОСОБНОСТЬ И НЕ ИЗМЕРИЛ ЕЁ ЦЕНУ.** Знакомство (163-2) построено правильно и проверено
прибором — но прибор проверял поведение, а не время. Три последовательных запроса вместо одного
прожили сутки и всплыли только на сквозном прогоне.
🔒 **Правило: способность, добавленная в горячий путь, измеряется в тот же час.** Прибор поведения
её не поймает по устройству.

🛑 **И ПЕРВЫЙ ПОРЫВ БЫЛ ОБЪЯСНИТЬ ВСПЛЕСК ХОЛОДНЫМ СТАРТОМ** — удобная и непроверяемая гипотеза.
Замер без записей её опроверг: всплески шли и на прогретой службе.

## Эволюция навыков

**Предложение для `use-testing`:** у прибора поведения и прибора цены разные предметы; зелёный
первый не говорит ничего о втором. Способность в горячем пути требует обоих.
