# 143-8 — идемпотентность, порядок записи и законы §3е в инструкции

**Коммиты:** `9a241d1` (паспорт и инструкция службы), `ba043c0` (федеральная инструкция).
**Дата:** 2026-09-08.

## Что делали и как

Проверили порядок и повтор прибором; перевели три статуса паспорта в «работает» **вместе с
разделом**; дописали в §3е таблицу построенного и честную границу; обновили обе инструкции.

**Порядок закона 2 §3е соблюдён буквально:** состояние пишется строкой выше побочных действий.

**Идемпотентность различена по родам, и это содержательно:**

| | Повтор закрытия ЦЕЛИКОМ | Повтор закрытия ШАГА |
|---|---|---|
| отзыв | **не просят второй раз** — помнит запись | — |
| ступень | не ставится по определению | **ставится ещё одна — так и задумано** |

🔒 **Ступеней в цепочке много, и каждая закрывается своей строкой** (закон 143-1). Объявить повтор
закрытия шага ошибкой значило бы запретить цепочку длиннее одного звена.

## Доказательства

**1. Прибор — повтор ведёт себя по роду:**

```
✓ второй раз отзыв НЕ спрашивают: отзыв по этому номеру уже запрашивали
✓ ПОВТОРНОЕ закрытие ШАГА ставит ещё одну ступень (1 → 2) — так и задумано
✓ после закрытия ЦЕЛИКОМ ступеней по-прежнему 1 — рода различаются
```

*Негативный контроль:* закрытие целиком с теми же полями ступени не добавляет ничего — счётчик
не слеп, он различает рода.

**2. Инструкции — статус правится вместе с разделом:**

```
§1  155 → ✅ работает (отставал сутки после закрытия 155)
§3е 143 → ✅ работает, хребет
§3и 148 → ✅ работает, «календарь пуст» снято
```

## Ошибки

- ✗ **Ревизия статусов снова понадобилась через сутки после предыдущей.** §1 стоял «замысел» при
  закрытом 155. 🔒 Это подтверждает закон 158-7а: **ревизия чисел и ревизия статусов — разные
  проходы**, и второй не делается сам собой.

## Эволюция навыков

🔒 **В `use-development-steps` просится строка: статус в карте правится ТОЙ ЖЕ ОПЕРАЦИЕЙ, что и
закрытие шага** — не «при следующей ревизии». Карта, отставшая на сутки, посылает следующего агента
строить построенное.
