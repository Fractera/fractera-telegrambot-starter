# Шаг 180 — вторая точка входа в подписку Claude: терминал активации в памяти

**Закрыт 2026-09-10.** Код: `fractera-memory-starter` `7f57fb5` (180-1…180-3) · `d5f98c1`
(`tsconfig.tsbuildinfo` убран из репозитория). План `new-steps/180/` удалён коммитом этого итога.

## Зачем

Слова владельца, дословно: «Речь о том, чтобы точка входа в подписку была не одна… если
пользователи проекта не захотят использовать чат, а захотят использовать память, чтобы они могли в
этой памяти активировать подписку… так как у нас уже это сделано в чате, то тебе просто перенести
это всё, настроить, делай». План — **«Подтверждаю все три»**.

Учётка Claude Code одна на весь сервер (`/root/.claude`) — вход, сделанный из памяти, действует и
для чата.

## Что сделано — копия чата и убранное лишнее

| Подшаг | Что дал |
|---|---|
| 180-1 | мост терминала: `node-pty`, `ws`, сокет `/pty` с одноразовым билетом, дверь билета, `/pty` выведен из-под привратника |
| 180-2 | страница `/{язык}/terminal`; пункт «Подписка Claude» в меню памяти — новой вкладкой, как «Терминал» у чата |
| 180-3 | убрано чужое: окно настройки агента (токен бота, ключ OpenAI), кнопка «Сессия агента», режим `claude-channel`, функции Telegram в `claude-cli.mjs`; кнопка входа входит сразу |

**Перенесены вместе с кодом и уроки чата:** лечение ловушки Next с событием `upgrade`
(`setupWebSocketHandler` + снятие обработчика) · `dev` объявляется явно (114-6) · громкий отказ
несобранного `node-pty` · окружение оболочки собрано явно — секрет машины в браузер не течёт.
Рабочая папка терминала — `/opt/fractera/memory`.

## Доказательства

**Плоскость A — HTTP.** Дверь билета без куки → `401 {"error":"unauthorized"}`; выдуманное соседнее
имя → `307` (открыто одно имя, не префикс) · `/ru/terminal` без куки → `307` на вход с
`requireRole=architect` · договор без секрета → `401` (не ослаб) · **сосед цел:** терминал чата → `307`.

**Плоскость B — сокет, прибор `development-docs/instruments/180-pty-probe.mjs`: 7 из 7.** По петле и
через домен по три соединения подряд — каждое **открылось** и закрыто нашим замком `1008
«bad-ticket»`, **ни одного `1006`**: ловушки Next, стоившей чату дня, нет. Молчание без `init` —
закрытие `1008 «no-init»` через 10 с. На сервере `node-pty` собран и грузится; строка старта:
`терминал ws://127.0.0.1:3700/pty`.

🛑 **НЕДОСТИЖИМОЕ ДЛЯ АГЕНТА, НАЗВАНО:** сам вход в подписку через страницу — это браузер и
аккаунт владельца. Вход тем же заблокированным аккаунтом не поможет — нужен другой. Не проверено,
подхватит ли живая сессия бота новый вход без перезапуска.

## Ошибки и находки

Отказов по ходу не было, и это результат, а не везение: все четыре ловушки были названы в плане до
кода и перенесены лечением. Закон «копируя экран, копируй то, на что он ссылается» (178) сработал
**заранее** — двери терминала названы привратнику до первой сборки.
**Попутно:** `tsconfig.tsbuildinfo` оказался в репозитории памяти с копией каркаса — убран и
внесён в `.gitignore`.
