# Шаг 180 — вторая точка входа в подписку Claude: терминал активации в памяти

## Пересказ и решение владельца

**Слова владельца 2026-09-10, дословно:** «Речь о том, чтобы точка входа в подписку была не одна… если
мы продублируем такое же решение в Memory, то мы сможем через Memory активировать подписку на весь
сервер, в том числе чат тоже начнёт работать… если пользователи проекта не захотят использовать чат,
а захотят использовать память, чтобы они могли в этой памяти активировать подписку… так как у нас
уже это сделано в чате, то тебе просто перенести это всё, настроить, делай».

**Предмет.** Учётка Claude Code одна на весь сервер (`/root/.claude`). Вход в подписку, сделанный из
памяти, действует и для чата. Нужна вторая равноправная точка входа — в памяти.

## Разведка — как это устроено у чата

Вход в подписку идёт **через терминал в браузере**: `claude auth login` печатает ссылку и ждёт код,
окно `auth-flow-modal` вставляет код в терминал. Дверь `agent-setup` только сообщает состояние
(`claude auth status`). Значит, перенос «как есть» — это перенос терминала целиком:

| Часть | Где у чата |
|---|---|
| страница и 4 компонента, словарь | `app/[lang]/terminal/` |
| мост сокета `/pty` и оболочка | `server.mjs` (node-pty, ws, режим `claude-login`) |
| одноразовый билет на сокет | `lib/fractera/pty-ticket.mjs`, `api/fractera/pty-ticket` |
| состояние подписки | `lib/fractera/claude-cli.mjs`, `api/fractera/agent-setup` |
| пакеты | `node-pty` (нативный), `@xterm/xterm`, `@xterm/addon-fit`, `ws` |
| правила привратника | `/pty` вне матчера, двери билета и состояния — поимённо |

## Известные ограничения — ловушки, уже оплаченные у чата

| Ловушка | Лечение, переносится вместе с кодом |
|---|---|
| Next забирает событие `upgrade`, сокет рвётся через 3 мс кодом `1006` | `app.setupWebSocketHandler?.(server)` + `server.removeAllListeners("upgrade")` |
| `ResizeObserver` будит сам себя, вкладка виснет | уже исправлено в скопированном компоненте |
| `node-pty` не собран — терминал молча не работает | `pnpm.onlyBuiltDependencies` + громкий отказ |
| дверь, сама проверяющая сессию, перехвачена привратником | имя двери — в привратник поимённо |

## Цена, названная до работы

🛑 **У памяти появляется оболочка `root` в браузере** — вторая такая точка на сервере после чата.
Замок тот же: роль `architect` и одноразовый билет на 60 секунд.
🛑 **Вход тем же заблокированным аккаунтом не поможет** — нужен другой аккаунт или ключ API.
🛑 **Не проверено:** подхватит ли живая сессия бота новый вход без перезапуска.

## Подшаги

| Подшаг | Результат |
|---|---|
| **180-1** | мост терминала в памяти: пакеты, сокет `/pty` с билетом, дверь билета, правила привратника |
| **180-2** | страница `/{язык}/terminal` скопирована; пункт «Подписка» в меню памяти |
| **180-3** | окно входа в подписку и состояние подписки; лишнее чата (токен бота, ключ OpenAI) убрано |

## Решения, принятые агентом

- переносится полный терминал, а не узкий «только вход» — по слову «просто перенести»;
- из окна настройки убраны части чата — токен Telegram и ключ OpenAI;
- рабочая папка терминала памяти — `/opt/fractera/memory`, а не папка бота.

## Чего в шаг не входит

Снятие блокировки Anthropic — выбор аккаунта за владельцем. Свой ключ API памяти. Ключи для чужих
сайтов.
