# 141-1 — `scope` объявлен: у признака появляется «от чего он зависит»

## Что строится
- `lib/facts/types.ts` — тип `FactScope = { key: string }` и необязательное поле `scope?: FactScope[]`
  в `Fact`; комментарий по образцу второго слоя: почему охват — ключ ДРУГОГО признака, а не словарь.
- `lib/facts/registry.ts` — чтение и запись поля; `REGISTRY-CONFIG/registry-config.json` и файлы
  записей его переживают без правки (поле необязательно).
- `lib/facts/detail.ts` — шестая строка раскрытия карточки: «от чего зависит».
- `app/[lang]/settings/_components/facts-registry.tsx` — показ строки; слова `en` и `ru`.
- `scripts/check-registry.mjs` — охват ссылается на СУЩЕСТВУЮЩИЙ ключ реестра, иначе сборка падает.

## Что считается готовым
Карточка признака с объявленным охватом показывает «зависит от: город»; у признака без охвата
строки нет вовсе, а не пустая.

## Чем доказывается
1. **Прибор по данным:** прогон `check-registry.mjs` на записи с охватом на несуществующий ключ —
   ненулевой код и названный ключ. **Негативный контроль:** та же запись с существующим ключом — 0.
2. **Сеть/разметка:** страница реестра отдаёт строку «зависит от» для правленой записи; заведомо
   ложная строка в той же выдаче — 0 совпадений.
