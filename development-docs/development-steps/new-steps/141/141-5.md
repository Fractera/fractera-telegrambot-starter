# 141-5 — накопление и жизненный цикл группируются по охвату

## Что строится
- `aggregate` (сумма, среднее, счёт, последнее) считается В РАЗРЕЗЕ `scope_key`.
- `lifecycle`: «текущее» состояние читается как последняя строка ВНУТРИ своего охвата.

## Что считается готовым
«Сколько я потратил на такси» отвечает по городам раздельно; истории двух одноимённых сущностей из
разных охватов не сливаются в одну ленту.

## Чем доказывается
1. **Прибор по данным:** шесть строк расходов в двух городах — две суммы. **Негативный контроль:**
   тот же прибор без группировки даёт одну сумму, равную их сложению, то есть прежнее поведение.
2. **База:** переходы состояний двух сущностей в разных охватах дают два независимых «текущих».
