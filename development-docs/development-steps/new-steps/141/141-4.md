# 141-4 — чтение с охватом: один вопрос, два города, два ответа

## Что строится
- Чтение фактов признака сужается по `scope_key` текущего разговора.
- Беспризорные факты (охват пуст) показываются ОТДЕЛЬНОЙ строкой с оговоркой, а не подмешиваются к
  охваченным и не прячутся.

## Что считается готовым
«Как вызвать такси» в Мадриде отдаёт мадридскую заметку; тот же вопрос в Лондоне — лондонскую;
заметка без охвата называется беспризорной.

## Чем доказывается
1. **База и прибор:** три записи — Мадрид, Лондон, без охвата; запрос с охватом Мадрида отдаёт
   мадридскую и называет беспризорную. **Негативный контроль:** тот же запрос с охватом Лондона
   отдаёт лондонскую — вывод обязан ОТЛИЧАТЬСЯ.
2. **Экран:** ответ на странице разбора показывает охват ответа словами, например «по данным для
   Мадрида».
