### 🔒 API — ЭТО И ЕСТЬ ЧЁРНЫЙ ЯЩИК, А НЕ ДЕТАЛЬ РЕАЛИЗАЦИИ

Решение владельца 2026-09-09 на вопрос «имеет смысл создать API?» — да. Без опубликованного
договора «отдельная служба» осталась бы переносом папки.

| Что | Как |
|---|---|
| форма | `POST /v1/<метод>` с JSON — путь версионирован, семантика глагольная: у памяти **методы**, а не ресурсы |
| договор | `GET /v1/contract` отдаёт сам договор машинно |
| **достижимость** | **только петля** (`127.0.0.1`) — решение владельца; как у `data :3300` и `geo :3400` |
| замок | общий секрет машины (`DATA_SECRET`), а не новый ключ: ключ ради одной двери надо кому-то выдавать и когда-то менять |
| версия | `v1` с первого дня. Служба без версии — служба, которую нельзя менять, не ломая потребителя |

🔒 **ИЗ ДОГОВОРА ПОРОЖДАЕТСЯ ВСЁ ОСТАЛЬНОЕ, И ЭТО ТРЕТЬЯ ГАРАНТИЯ ОТДЕЛЬНОСТИ.** Схемы инструментов
агента приходят **из `GET /v1/contract` по HTTP**, а не импортом файла. Пока схема берётся
импортом — отдельность есть договорённость; когда по HTTP — факт. ✗ Сегодняшний дефект
(`memory_write` недостижим сутки) прошёл ровно через импорт.

🛑 **ПЕТЛЯ НЕ ОСЛАБЛЯЕТ ГРАНИЦУ.** Граница здесь — **граница процесса**, а не сети: импортировать
через неё нельзя в принципе, кто бы куда ни ходил.

- **В 175-1 у договора НОЛЬ методов.** Он существует и отдаётся; наполнять его будем осознанно,
  по одному, начиная с самого простого. Пустой договор — правильное состояние этого подшага.
- **`GET /v1/health`** — единственная работающая дверь: отвечает версией и говорит, что жива.
- 🔒 **СТОРОЖ ГРАНИЦЫ С ПЕРВОГО ДНЯ**, а не когда-нибудь: любой импорт внутренностей памяти из
  репозитория бота роняет сборку бота. Строится **до** первой строки логики — иначе он появится
  после первого нарушения, то есть поздно.
- **Строка в `lib/bootstrap.sh`** (FES): без неё новый сервер родится без памяти и не скажет об этом.

## 2. Что считается готовым

Служба живёт на своём порту, отвечает `/health`, лежит в своём репозитории, и сторож не даёт боту
импортировать её внутренности. **Памяти внутри пока нет — и это правильное состояние.**

## 3. Чем доказывается — две плоскости, названы заранее

**Плоскость 1 — процесс и сеть (машина).** `curl` на порт даёт `200` с версией договора; `pm2`
показывает процесс, `uptime` растёт; слушатель **не сирота** (`ppid` ≠ 1).
**Негативный контроль:** приложение бота на `:3600` **остановлено** — служба продолжает отвечать.
Это и есть доказательство отдельности: пока они падают вместе, отдельности нет.

**Плоскость 2 — граница (сторож).** `npm run build` в репозитории бота проходит; подложенный импорт
`lib/memory/*` из нового кода **роняет сборку** с названным файлом.
*Как выглядело бы без правки:* импорт по файловому пути проходит молча — ровно так сегодня и живёт
`intake-preloader.js:721`.
