# 142-2 — публичный корень: первая дверь в стене, и она одна

## Что строится
- Отдельный корень маршрутов вне замка; `proxy.ts` пропускает только его.
- `app/robots.ts`: разрешён публичный корень, запрещено всё остальное.
- `sitemap` только из публичных договоров; выключенная публичность из него исчезает.

## Что считается готовым
Публичная страница открывается без сессии; любая служебная по-прежнему отдаёт `404` без роли.

## Чем доказывается
1. **Сеть:** публичный адрес без куки — `200`. **Негативный контроль:** `/{lang}/settings` без куки
   в том же прогоне — `307`/`404`, то есть замок цел. Оба измерения в одном выводе, иначе доказано
   только одно.
2. **Файл:** `robots.txt` службы содержит `Allow` публичного корня и `Disallow: /`; заведомо ложный
   путь в нём — 0 совпадений.
