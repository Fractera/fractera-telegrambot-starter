# 143-6 — отзыв: просят один раз, ответ ложится в поля вердикта

## 1. Что строится

- `app/api/agent/feedback/route.ts` — дверь: `automation_id` + `liked`/`needs_work` → запись.
- `lib/automations/store.ts` — писатель вердикта уже есть (`setAutomationFields`), у него появляется
  вызывающий; сегодня поля только читают.

🔒 **ЗАКРЫТИЕ НЕ СПРАШИВАЕТ САМО** — оно возвращает решение «спросить», а спрашивает агент словами
человека. Второй канал вопроса был бы второй реализацией отзыва (§3б, шаг 139).

## 2. Что считается готовым

Вердикт записан; повторное закрытие того же номера решения «спросить отзыв» больше не возвращает.

## 3. Чем доказывается

- **Прибор:** запись вердикта → повторное закрытие → решение `feedback` = нет, причина «уже
  спрашивали». **Негативный контроль:** до записи то же закрытие давало «да».
- **Дверь:** без секрета — `401`; с секретом и негодным вердиктом — `400` с названной причиной.

143-4.
