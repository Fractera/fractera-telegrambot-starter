# 164-5 — паттерн неизвлекаемого вопроса, выделенный из кейса «Денис и президент»

## Что строится
- `development-docs/reports/patterns-question-whose-answer-is-not-in-our-data.md` — разбор кейса и
  **семь признаков** вопроса, ответ на который нельзя извлечь напрямую, плюс шаблон «история → тест».
- Ссылка на него из `MEMORY-STANDARD.md` §9 (карта проверки) — одной строкой, без копии текста.

## Что считается готовым
Кейс Дениса разложен по семи признакам без остатка, и по тому же шаблону выписаны десять пар
«история → вопрос», ни одна из которых не содержит слова вопроса в своих данных.

## Чем доказывается (две плоскости, названы заранее)
1. **Текст против прибора:** каждый признак паттерна показан строкой из
   `scripts/probe/case-denis-president-162-7.mjs`, которая его проверяет. Признак без строки прибора
   — выдумка и вычёркивается.
2. **Механическая проверка корпуса (несёт негативный контроль):** скрипт печатает для каждой из
   десяти пар пересечение слов вопроса со словами истории и таблицы. Ожидается ноль по ключевому
   слову; **негативный контроль — кейс Дениса со словом-подсказкой** («президентский полк»), где
   пересечение обязано быть НЕ нулевым, иначе проверка слепа.

## На что опирается
164-1 … 164-4 закрыты; прибор 162-7 существует и зелёный.

## Чего не входит
Постройка корпуса в памяти (это 164-6) и прогон вопросов (164-7).
