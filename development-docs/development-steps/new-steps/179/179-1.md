# 179-1 — память: после выхода страница приветствия с двумя дорогами

## 1. Что строится

| Файл | Что с ним |
|---|---|
| `app/[lang]/welcome/` | копия с чата: страница, карточка, словарь |
| `lib/fractera/auth-url.ts` | копия с чата; `publicAuthUrl()` выводит адрес входа из **любого** поддомена |
| `app/[lang]/welcome/_components/welcome.tsx` | вторая кнопка — «Вернуться на главную» |
| `proxy.ts` | `/{язык}/welcome` открыт без входа; выход ведёт на него |

## 2. Что считается готовым

Выход из памяти приводит на `memory.<домен>/{язык}/welcome`; на странице две кнопки — «Войти» на
экран входа с возвратом в память и «Вернуться на главную» на `/{язык}`.

## 3. Чем доказывается — две плоскости, названы заранее

**Плоскость A — маршрут выхода.** `/logout?lang=ru` → `307`, и `redirectUrl` в адресе службы входа
оканчивается на `/ru/welcome`. **Негативный контроль:** до правки он оканчивался на `/ru`.

**Плоскость B — отданный HTML страницы без входа.** `/ru/welcome` → `200`; в разметке ссылка на
`auth.<домен>/login?callbackUrl=` и ссылка на `/ru`. **Негативный контроль:** слова «Адрес службы
входа пока не настроен» — 0, иначе помощник не вывел адрес.
