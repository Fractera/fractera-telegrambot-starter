# 142-3 — страница ответа: из фактов, с охватом в адресе и моментом верности

## Что строится
- Статическая страница (ISR) по адресу вида `<публичный корень>/<имя>/<охват>`.
- Тело собирается ИЗ ФАКТОВ по договору; модель на запрос не зовётся.
- Момент, на который ответ верен, написан словами на самой странице.

## Что считается готовым
Человек открывает адрес и видит ассортимент, цену и наличие для названного охвата, с датой ответа.

## Чем доказывается
1. **Сеть:** страница для Мадрида содержит мадридскую цену. **Негативный контроль:** та же страница
   для Лондона содержит другую — вывод обязан ОТЛИЧАТЬСЯ, а не просто быть непустым.
2. **Прибор:** счётчик обращений к модели при отдаче страницы равен нулю.
