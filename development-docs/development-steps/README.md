# Шаги разработки — как ведётся работа в этом репозитории

Этот файл отвечает на вопрос **«что здесь лежит и куда что писать»**. Как работать — навык
`.claude/skills/use-development-steps`; что за продукт — `development-docs/PASSPORT.md`. Копий между
ними нет намеренно: две копии расходятся, и следующая сессия исполняет устаревшую.

## Пять адресов

| Адрес | Что внутри |
|---|---|
| `current-steps.md` | **где работа СЕЙЧАС.** Читается ПЕРВЫМ в каждой сессии — раньше плана и раньше кода |
| `new-steps/<N>/` | план предстоящего: `<N>-main.md` плюс ТЗ каждого подшага отдельным файлом |
| `completed-steps/` | итоги закрытых подшагов: `<N>-<подшаг>.md`, `<N>-main.md` |
| `pre-steps/` | приёмная заявок ИЗВНЕ — их пишет не агент разработки |
| `../reports/` | подробные разборы: `errors-` — один отказ, `feature-` — законченная способность |

🔒 **`current-steps.md` — не список шагов, а состояние проекта.** План говорит, что было задумано, и
молчит о том, что уже сделано. Способность переживает десятки сессий; файл состояния — единственное,
чем работа переживает конец сессии.

## Три правила, без которых остальное не работает

**1. 🔒 Каждая правка ложится коммитом, сразу.**
Это единственное жёсткое требование репозитория и цена того, что агенту здесь разрешено править всё,
включая свои инструкции. Без коммита откатывать нечего.

**2. 🔒 Подшаг закрывается двумя доказательствами из РАЗНЫХ плоскостей, и одно несёт негативный
контроль.**
Сборка не бывает ни одним из двух: её лог выглядит одинаково, работает способность или нет.
✗ оплачено 2026-09-06 — `TSC_RC=0` и `BUILD_RC=0` были зелёными, а страница падала в рантайме на
отсутствующем контексте темы; отказ нашёл владелец, открыв её в браузере.

**3. 🔒 Итог называет хэш коммита.**
Итог без хэша — незакрытый подшаг: владелец открывает `completed-steps/`, видит запись и не может
проверить, что за ней стоит.

## Нумерация

**Сквозная и общая с федеральным слоем** (`/code/development-docs/development-steps/`). Начать здесь
с единицы значило бы дать имя «шаг 5» двум разным работам. Следующий свободный номер виден в
`completed-steps/`.

## Кто здесь работает

**Двое, и они читают разные файлы.**

| | Агент канала Telegram | Агент разработки |
|---|---|---|
| что читает | `CLAUDE.md` в корне — рабочая карточка | этот файл, навык, планы шагов |
| чем занят | отвечает человеку, принимает входящее | строит и улучшает проект |
| право на правку | **есть** — репозиторий открыт обоим | есть |
| обязанность | коммит на каждую правку | коммит на каждую правку |

🔒 **ПРОЕКТ САМО ЭВОЛЮЦИОНИРУЮЩИЙ (решение владельца 2026-09-06).** Инструкции и навыки здесь не
только исполняются — они улучшаются тем, кто ими пользуется. Увидел, как сделать лучше, — сделай и
объясни в сообщении коммита, чем правка оплачена.

🔒 **ОТМЕНЁННОЕ ПОМЕЧАЕТСЯ, А НЕ УДАЛЯЕТСЯ:** 🪦 с датой и причиной, рядом названо заменившее.
Бесследно удалённое правило следующая сессия воскрешает по памяти — неточно и как новость.
